# 灵珠桌面端原型

## 实施规划

1. 保持当前三栏科技感工作台与动态核心，只让会话内容和操作状态改为数据驱动。
2. 使用浏览器本地存储保存原型会话和当前会话，实现新建、切换、刷新恢复及按名称/内容搜索。
3. 贯通空闲、执行、审批、批准完成、拒绝、取消、失败、重试和刷新中断恢复状态；明确标记这是模拟流程，不连接后端，也不写入真实文件。
4. 用 Playwright 覆盖各主要交互、刷新恢复、键盘操作、浏览器控制台与桌面/窄视口布局。
5. 运行原型专项测试及现有项目测试，修复发现的问题并保留实时预览服务。

## 本地预览

在仓库根目录运行 `node backend/workbench/server.js`，浏览器打开 `http://127.0.0.1:4173/`。

真实工作台入口为 `/live.html`。预览服务首次访问 `/api/` 时启动同一工作区的本地 Gateway；界面读取真实会话、模型和诊断，支持新建会话、搜索标题、切换模型、提交/停止回合及处理回合审批。服务仅监听本机地址。权限菜单提供 Safe 和个人文件模式：个人模式允许普通文件读写直接执行，但不放开命令、删除、联网或其他高风险能力。若沙箱或审计不可用，Safe 回合按后端策略失败关闭；个人文件回合仍保留审计、受保护路径和其他项目写入检查。

插件与技能管理入口为 `/extensions/plugins`，也可从工作台侧栏进入。该页面是本地管理原型：公开目录条目为演示数据；添加、启停仅修改管理状态，不调用真实插件运行时、外部服务或技能执行引擎。个人技能支持编辑正文、版本化 JSON 导入/导出和彻底删除；卸载仅移除安装记录。管理数据以 schemaVersion 1 保存在 `.agent-data/extensions-manager.json`，技能正文与元数据分开关联保存。导入当前仅支持本页面导出的技能格式，不导入插件或敏感配置。

## 功能测试

在仓库根目录运行 `npm run test:ui`。测试覆盖工作台与插件/技能管理页面，使用本机 Microsoft Edge；如未安装，可通过 `PLAYWRIGHT_CHROMIUM_EXECUTABLE` 指定兼容 Chromium 的可执行文件。

测试场景也可在预览中单独查看：

- `/?scenario=empty`：空会话
- `/?scenario=success`：成功完成
- `/?scenario=approval`：等待审批
- `/?scenario=failure`：失败与重试
